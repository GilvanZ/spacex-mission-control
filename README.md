# SpaceX Mission Control

A real-time SpaceX launch tracker that displays past and upcoming missions, rocket fleet data and launch statistics.

Built as a portfolio project to practice Next.js, TypeScript and REST API consumption.

## 🚀 Live Demo

[spacex-mission-control.vercel.app](https://spacex-mission-control.vercel.app)

## Technologies

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- SpaceX REST API (api.spacexdata.com)

## Features

- Past launches with mission patch, date and status
- Upcoming scheduled missions
- Rocket fleet overview
- Data fetched server-side with Next.js async components

## Getting Started

Clone the repository and install dependencies:

```bash
git clone https://github.com/GilvanZ/spacex-mission-control
cd spacex-mission-control
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
